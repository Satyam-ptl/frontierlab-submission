# AI assistance disclosure

AI tools assisted with project planning, source organization, code scaffolding, documentation drafting, test-case generation, interface refinement, and PDF generation. The submitting team must review the central claim, source evidence, calculations, code behavior, limitations, accessibility, and final submission, and remains responsible for the work.

## File-level register
- `src/`, `scripts/`: AI-assisted scaffolding and implementation; tests executed in the build environment.
- `docs/`, `README.md`: AI-assisted drafting; factual citations require final human source review.
- `public/data/`: AI-assisted normalization from cited sources; no empirical value should be accepted without team verification.
